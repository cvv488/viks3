v1.0 19-05-2026
- вначале реализуется передача сообщений без привязки к протоколу Викинг
- реализованы тестовые клиенты в simulate которые:
 - авторизуются на Сервере
 - периодически шлют сообщение ping ожидая pong
 - один из клиентов периодически шлет info сообщение для другого
- СС слушает порт
- СС принимает сообщение с аутентификацией - проверяет - отвечает auth_ok - регистрирует клиента
- запускает его слушателя который при получении сообщений:
    - ping отвечает pong
    - info находит клиента и перенаправляет ему сообщение
